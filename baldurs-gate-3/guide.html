    Q1. 당장 금화를 구하는 방법 (2026-09-27)

    인벤토리 상단 숫자 읽는 법: 캠프파이어 아이콘 = 야영 물자(53), 기둥 모양 아이콘 = 금화(66, Wyll 소지). 금화는 캐릭터마다 따로 들고 다녀요.

    1. 책 팔기 (가장 빠름)- Wyll 가방의 책 20권 정도를 마이코니드 군락 상인 블러그, 데리스에게 판매.- 주황색 테두리 아이템은 팔지 말 것 — 퀘스트·이야기 아이템.

    2. 잡동사니 · 남는 무기 팔기- 쓰지 않는 무기, 방어구, 은식기·술병 같은 잡템.- 음식은 팔지 말 것 — 긴 휴식에 야영 물자로 쓰여요.- 두루마리는 게일이 배울 수 있는 것만 남기고 나머지는 팔아도 됨.

    3. 거래는 Wyll로- 매력이 가장 높아 판매가가 가장 좋아요. 파는 캐릭터를 Wyll로 바꾸고 거래.- 상인도 금화가 한정돼 있어요. 상인 금화가 바닥나면 금화 대신 물건으로 교환(물약, 화살 등).

    4. 탐험하며 줍기- 언더다크 곳곳의 상자·시체, 특히 비전의 탑과 셀루네 전초성에 금화와 팔 물건이 많아요.- 아스타리온으로 잠긴 상자를 전부 따기.

    목표 금액- 게일 리스펙 100골드 → 책만 팔아도 충분히 가능.- 3명 모두 리스펙하려면 300골드 이상 → 비전의 탑 탐험 후.

    Q2. 골드 없이 게일 방어도 올리기 (2026-09-28)

    1순위: 마법사 갑옷(Mage Armor) 주문 — 돈 0원- 게일 주문서에 마법사 갑옷이 있는지 확인. 있으면 전투 전에 걸기(긴 휴식까지 유지, 1레벨 슬롯).- 방어도 11 → 14. 방패까지 들면 16. 가죽 갑옷보다 좋아요.- 갑옷을 입고 있으면 적용 안 됨. 게일은 로브 그대로.

    2순위: 가방·야영지 보관함 뒤지기- 인벤토리 검색창에 "갑옷" 입력. 고블린·도적에게서 주운 가죽 / 누빔 / 징박은 가죽 갑옷, 방패가 있을 수 있어요.- 게일은 인간 종족 특성 민병대 덕분에 경갑과 방패 숙련이 있어요.- 아스타리온의 갑옷은 벗기지 말 것.

    3순위: 물물교환- 금화가 0이어도 거래 가능. 블러그·데리스 거래창에서 책을 넘기고 갑옷·방패를 가져오면 값이 상쇄돼요.- 거래는 매력이 높은 Wyll로.

    Q3. 게일 점검 — 129골드 확보 (2026-09-28)

    완료- ✅ 회복의 애뮬릿 착용, 치유의 단어 · 다중 치유의 단어가 단축바에 추가됨- ✅ 금화 129 (게일 소지)

    남은 것- 방어도 여전히 11 → 방패부터 (Q4 참고).- 실격자의 애뮬릿이 아직 가방에 있음 → 게일과 대화해서 건네기(워터딥의 위저드 "!").- 야영 물자 13 → 긴 휴식 1회에 40 필요. 음식은 팔지 말고 줍기, 모자라면 상인에게서 음식 구매.

    금화 사용 순서1. 게일 갑옷 · 방패 구매2. 남은 금화 + 책 판매로 100 모으기 → 위더스에서 게일 리스펙

    Q4. 데리스의 갑옷이 비싸요 (2026-09-28)

    데리스가 파는 생가죽 갑옷+1 (231골드) 은 사지 말 것.- 평갑(중갑) 이라 게일은 숙련이 없어요 (툴팁의 주황색 "평갑에 숙련되지 않음"). 입으면 주문을 못 쓰고 명중도 떨어져요.- 게일이 입을 수 있는 건 경갑(누빔 · 가죽 · 징박은 가죽)과 방패뿐.

    로브 + 방패13가장 쌈
    마법사 갑옷 + 방패16최선

    결론1. 방패만 사기. 상인 목록에서 "방패"를 찾거나, 동료 가방·야영지 보관함 확인.2. 게일이 마법사 갑옷 주문을 알면 전투 전에 걸기. 갑옷은 필요 없음.3. 비싼 건 금화 대신 책을 거래창에 올려서 값을 맞추기. 거래는 Wyll로.

    Q5. 방패를 상점 말고 구하는 곳 (2026-09-28)

    1. 이미 가진 것부터 (0골드)- 파티 4명 가방 + 야영지 보관함에서 "방패" 검색.- 야영지의 라에젤 · 카를라크 가방도 확인.

    2. 다녀온 곳의 시체 다시 뒤지기- 고블린 캠프(폐허가 된 성소): 고블린 전사들이 나무 방패를 많이 들고 있어요. 시체는 사라지지 않으니 순간 이동진으로 가서 줍기.- 떠오르는 길 · 황폐한 마을의 적 시체도 마찬가지.

    3. 앞으로 얻을 곳- 그림포지 아다만틴 대장간: 미스랄 광석 + 틀로 아다만틴 방패를 만들 수 있어요(갑옷 대신 선택). 게일이 들 수 있는 1막 최고급 방패.

    4. 장비 없이 방어도 올리는 주문- 게일 방패(Shield) 주문: 맞기 직전 반응으로 방어도 +5. 주문서에 있으면 준비해 두기.- 섀도하트 신앙의 방패: 동료 한 명 방어도 +2 (집중 주문).- 게일 마법사 갑옷: 로브 대신 방어도 14.

    Q6. 야영지 점검 — 방패 없음 (2026-09-28)

    • 야영지 보관함 · 라에젤 · 윌(동료) · 카를라크 가방에 방패 없음.
    • 보관함에 갑옷 3벌(붉은 갈색 조끼, 회색 사슬 셔츠, 파란 천 갑옷)이 있음 → 툴팁에 "경갑" 이라고 적힌 것만 게일이 입을 수 있음. 사슬 셔츠는 평갑이라 불가.
    • 라에젤 가방에 반지 1개가 그냥 들어 있음 → 효과 확인 후 파티원에게 착용.
    • 확인 결과: 붉은 갈색 조끼 = 가죽 갑옷(경갑, 방어도 11) → 게일 착용 시 방어도 12. 단, 마법사의 갑옷(14)이 더 좋아서 입히지 않음 (Q7).
    • 마법사 갑옷 주문을 쓸 땐 갑옷을 벗어야 함(마법사 갑옷 쪽이 14로 더 높음).
    • 다음 수단: 고블린 캠프 시체에서 나무 방패 줍기 → 가죽 갑옷 + 방패 = 14.

    Q7. 게일은 마법사의 갑옷을 이미 알고 있음 (2026-09-28)

    • 단축바 아래 줄의 노란 방패 아이콘 = 마법사의 갑옷 (1레벨 방호술, 긴 휴식까지 유지).
    • 방어도 = 13 + 민첩(+1) = 14. 가죽 갑옷(12)보다 높음.
    • 조건: 갑옷을 입고 있으면 안 됨 → 가죽 갑옷은 입히지 말고 로브 그대로.
    • 사용법: 긴 휴식 직후, 전투 밖에서 한 번 걸어두기. 1레벨 슬롯 하나로 하루 종일 유지.
    • 나중에 방패를 구하면 16.

    ⚔️ 장비 업그레이드 목표

    • 그림포지 아다만틴 대장간: 미스랄 광석 + 틀 → 아다만틴 판금(Wyll) 또는 아다만틴 비늘 갑옷(섀도하트). 1막 최고 방어구.
    • 골드 목표: 리스펙 300 + 주문서 학습비.
