## 그래픽 · 컨트롤러 세팅

### 패드 설정 — 레이저 울버린 V3 프로 8K PC (2026-10-16)

**세키로 기본 조작(Xbox 레이아웃)**
LT 갈고리(Grappling Hook) / LB 튕겨내기(Deflect), 길게 가드 / RT 의수 인술(Prosthetic Tool) 사용 / RB 공격 / A 점프 / B 스텝 회피(Step Dodge), 길게 달리기 / X 행동·줍기 / Y 의수 인술 전환 / 십자키 위 아이템 사용, 좌우 아이템 전환, 아래 엿듣기 / 왼스틱 누름 웅크리기 / 오른스틱 누름 록온 / LB+RB 유파 기술(Combat Arts)

**원칙**: 오른손 엄지에 몰린 A(점프)·B(회피)·Y(의수 전환)를 뒷면 패들로 빼서 엄지를 카메라 스틱에서 떼지 않게 한다. 패들은 "기존 버튼 복사"라서 게임 내 키 설정은 손대지 않는다(기준은 Razer Synapse 4 한 곳).

**Synapse 4 프로파일 `Function(○) + Y : Sekiro`**

| 버튼 | 매핑 | 용도 |
|---|---|---|
| M1 (왼쪽 위) | A | 점프 — 하단 쓸기 위험 공격(Perilous Attack) 뛰어넘기 |
| M2 (오른쪽 위) | B | 스텝 회피 — 간파(Mikiri Counter) 입력 |
| M3 (왼쪽 가운데) | Y | 의수 인술 전환 |
| M4 (오른쪽 가운데) | RB (오른쪽 범퍼) | 공격. 록온(오른스틱 누름)으로 바꾸는 것도 고려 |
| M5 · M6 (아래) | 비활성 | 익숙해지면 십자키 위(아이템) / 왼스틱 누름(웅크리기) 후보 |

- 폴링레이트 1000 Hz, 십자키 8-WAY.
- 트리거: 세키로는 RT·LT가 디지털 입력이라 헤어 트리거(뒷면 트리거 스톱 잠금)로 짧게 끊어도 됨.
- 온보드 프로파일은 4개(○+A/B/X/Y)가 최대. 현재 A 붉은사막 / B Dark Souls1 / X 스트리트파이터5 / Y Sekiro. 더 필요하면 슬롯을 덮어쓰거나 장르별로 묶는다(다크소울은 M1=A, M2=B 그대로 써도 손해 없음).
- 드롭다운 전환이 1번으로 되돌아가면 ○+Menu+X(Xbox 모드) → ○+Menu+A(PC 모드)로 재인식시킨다.
- Steam 입력(Steam Input)이 끼어들어 버튼이 중복되면 Steam → 세키로 속성 → 컨트롤러 → "Steam 입력 사용 안 함". (확인 필요: 실제 게임에서 중복 여부)
